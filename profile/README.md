## About

Blackhole Dynamics is an independent engineering umbrella for open-source software, developer tooling, governance frameworks and modular system architectures.

Our development process is deliberately AI-assisted and includes **vibe coding** as part of how ideas are explored, prototyped and iterated. AI is used extensively as an engineering collaborator, while architecture, governance, verification and release decisions remain under human control.

The organization provides a stable home for projects while preserving individual authorship and contribution history.

## Engineering principles

- **Standalone-First** — integrations must not become lock-in.
- **Clear authority boundaries** — strategy, engineering governance, evidence and operations remain distinct.
- **Modular architecture** — capabilities should compose without unnecessary runtime coupling.
- **Auditable development** — decisions, work packages and releases should remain traceable.
- **Human-maintained releases** — repository ownership belongs to the organization; authorship remains attributable to contributors.
- **Vendor-neutral by design** — external tools may accelerate work without becoming mandatory architectural dependencies.
